# みんなの川（river-for-all）

街なかを流れる、運河のような細い川の観察記録です。
通勤の行き帰りに同じ場所から写真を撮り、海の潮の満ち引きとくらべています。

カモも、魚も、上流から来る水も、海から押し戻されてくる水も、みんな行き来している川なので「みんなの川」。

> 地名はすべて仮の名前にしてあります（「階段」「上の滝」など）。いつか本当の名前に戻すかもしれません。

![見取り図](figures/river.svg)

## 最初の問い

**この川は、海の潮で逆流するのか？**

2026年9月から写真を撮りためて、11月に答えが出ました。

## 分かったこと

### 1. 逆流する

港が上げ潮のあいだ、川の水は上流へ向かって流れます。

決め手にした観察（どれも、さざ波ではなく浮いているものの動きで確かめています）：

- 11/24 16:40　ほぼ無風。浮いている葉っぱが1分で画面の幅の半分ほど上流へ
- 11/25 12:56　川全体が、ゆるやかに上流へさかのぼっていた
- 逆向きの確認：同じ場所で、下げ潮のときには下流へ流れている（11/20 16:38、11/25 12:28 など）

### 2. 潮がとどくのは「上の滝」の足元まで

干潮のとき白く波立っていた「早瀬」は、満潮では丸ごと沈みます。
でも「上の滝」（川底の段差）は、潮がいちばん高い時間でも上から下へ水が落ちていました。
逆流の上限は、上の滝の足元です。

### 3. 干潟が出るか沈むかの境目

港の推算潮位でだいたい **116〜132cm** のあいだ。それより低いと「階段」の下に泥の干潟が出て、高いと沈みます。

![港の潮位と、階段で見た水位](figures/threshold.svg)

### 4. 港より、20〜40分ほど遅れて変わる

港の潮が折り返しても、「階段」の流れはすぐには変わりません。

- 干潮のとき（11/25）：港の干潮から **24〜46分後** に、流れが下流→上流へ
- 満潮のとき（11/27）：港の満潮から **約27分後** に、川全体が下流へ。水位が下がり始めたのは約20分後

![港の潮の折り返しと、階段の流れの向き](figures/turns.svg)

## 外れた予想、変わった考え

この観察のいちばん面白いところは、たぶんここです。予想が外れるたびに、川のことが少しずつ分かってきました。

- **「港の満潮の直前なら、まだ下流へ流れているはず」（11/24）** → 外れ。上流へ流れていた。遅れの考え方そのものを読み違えていた
- **「さざ波の向き＝流れの向き」** → 外れ。11/20、さざ波は上流へ走っているのに、浮いている小枝は下流へ流れていた。風のしわざ
- **「上げ潮なら上流へ流れる」（11/26 16:35）** → 外れ。上げ潮のまっ最中なのに、流れは止まっていた。上の滝が近い行き止まりのような場所なので、水位は上がっても流れは弱いのかもしれない
- **「潮は浅いところから先に変わる」（11/26〜27）** → 怪しくなった。手前と奥で流れが逆向きになる現象を、最初はこう考えた。でも11/27 9:00、下げ潮なのに手前だけ上流へ流れて、すぐまた戻った。今は、川に張り出した階段の影にできる**渦**ではないか、と考えている
- **「満潮側の遅れは、干潮側より短いはず」** → まだ白黒つかない

## まだ分からないこと

- 手前と奥で流れが逆になるのは、本当に階段の影の渦なのか
- 満潮側と干潮側で、遅れの長さはちがうのか
- 港の推算潮位と、現地の水位がときどき合わない（11/19と11/20）のはなぜか。予報の潮位と実際の潮位のずれ（潮位偏差）かもしれない
- 上流から送られてくる水の出口は、本当にあのアーチ形の口なのか（干潮のときに見に行く）
- 時間差は、港から「階段」までの距離と川の深さで説明できるのか

## 脇役たち

- **カモ**：カルガモ、オナガガモ、コガモ。11月の終わりには、オスがメスを追いかけて、笛のような声で鳴き合っていた
- **大きな魚影**：1mくらいに見えた（水の中のものは大きく見えるので、実際はもう少し小さいかも）。ボラかもしれない
- **鉄の膜**：岸ぎわの水面に、虹色の薄い膜。傘でなぞると線が描けて、閉じずに割れたまま残った。油ではなく、鉄バクテリアの膜
- **湧き口の緑**：湧き水の下の泡立つ緑は、顕微鏡で見ると糸のような藻。トリボネマという黄緑藻ではないか、という説。珪藻も一緒にいた

## 観測のしかた

- いつも同じ場所（「階段」の車止め）から、同じ向きで撮る。写真の左が下流
- 流れの向きは、**浮いているもの**（葉っぱ、泡のかたまり）が**動かない目印**（壁の札、水面に映った街灯）に対してどちらへ動くかで決める。さざ波は風で動くので使わない
- 風の強さもメモする
- 手前と奥で向きがちがうことがあるので、川の向きは**奥か真ん中**で見る
- 水位は、階段の何段目まで水が来ているかと、壁に残った濡れた帯で見る

## データ

- [`data/observations.csv`](data/observations.csv)：観察の記録（日付、時刻、地点、港の推算潮位、水位の見た目、流れの向き、メモ）
- [`data/harbor_tide_hourly.csv`](data/harbor_tide_hourly.csv)：港の推算潮位の毎時値（図に使った日の分）

港の潮位は、気象庁が公開している潮位表の推算潮位（天体の動きから計算した予報の値）です。観測した時刻の値は、毎時値から内挿しています。実際の潮位は、気圧や風で10〜20cmほどずれることがあります。
